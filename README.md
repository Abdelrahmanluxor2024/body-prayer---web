تطبيق ويب احترافي خفيف جداً لمواقيت الصلاة في **محافظة الأقصر** ومدنها (إسنا، أرمنت، القرنة، البياضية، الطود، الزينية...)، أعدّه ويطوره **عبد الرحمن ياسر الاسيوطي**.

A fast, lightweight, professional prayer-times web app for Luxor, Egypt.

## ✨ المزايا | Features

- 🕌 مواقيت الصلوات الخمس + الشروق بتنسيق 12 ساعة (ص / م)
- ⏱️ ساعة حية بالثواني بنظام **12 ساعة (ص / م)** و**بتوقيت الأقصر دائماً** (حتى لو كان الزائر خارج مصر) + التاريخ الميلادي والهجري بالعربية
- 🔮 بطاقة الصلاة القادمة مع عداد تنازلي دقيق وشريط تقدّم
- 🌗 **اكتشاف تلقائي للتوقيت الصيفي / الشتوي** حسب قانون التوقيت الصيفي المصري (آخر جمعة من إبريل → آخر خميس من أكتوبر) مع إمكانية التثبيت اليدوي من زر التوقيت
- ✏️ تعديل الاسم المعروض (محفوظ في المتصفح)
- إظهار / إخفاء وقت الإقامة بجوار كل صلاة
- تنبيهات بصرية هادئة عند دخول وقت الصلاة (بدون صوت)
- جدول الشهر الكامل لأي شهر من شهور السنة الـ 12، مع عرض كل يوم بالتوقيت الصحيح له (صيفي/شتوي) وتمييز يوم التحويل
- 🖼️ **تحميل كارت مواقيت اليوم كصورة بمقاس 3:4** (1080×1440 تُصدَّر بدقة 2160×2880) بتنسيق احترافي: أيقونة كل صلاة بجوار اسمها، مواعيد كبيرة واضحة، التاريخ الميلادي والهجري بخط كبير، واسم المطوّر **بين تاجين** — جاهزة للمشاركة على واتساب وفيسبوك (وعلى iOS تُفتح قائمة المشاركة مباشرة)
- 📲 قابل للتثبيت على الشاشة الرئيسية (Web App Manifest + أيقونات محسّنة)
- 📞 قسم تواصل مع المطوّر بتصميم متماشٍ مع ثيم الموقع (اتصال مباشر + واتساب + نسخ الرقم)
- 📖 قسم «عن الموقع» يشرح التطبيق ومميزاته + قسم «طريقة حساب المواقيت» + «نطاق التغطية» + **الأسئلة الشائعة (FAQ)** حتى لا يتوه المستخدم
- 🧭 شريط تنقّل سريع بين أقسام الصفحة
- أيقونات فيكتور SVG راقية وموحدة دون استخدام الإيموجيز الشائعة
- 🎨 ثيم فخم ليلي (Royal Navy + Gold) + **خطوط عربية احترافية: Noto Kufi Arabic للعناوين، IBM Plex Sans Arabic للواجهة والأرقام، وAmiri للنص القرآني**
- ⚡ Pure HTML/CSS/JS — بدون أي تبعيات ثقيلة أو Build step
- 📱 Responsive كامل (موبايل / تابلت / ديسكتوب)
- 🔍 SEO احترافي: بيانات منظّمة (WebApplication + FAQPage + BreadcrumbList + Place) ومحتوى مرئي مكتوب بعناية + دعم محركات البحث بالصور

## 🚀 التشغيل المحلي | Run Locally

لا تحتاج أي تبعيات — افتح `index.html` مباشرة في المتصفح، أو استخدم أي سيرفر ستاتيك:

```bash
# Python
python -m http.server 8080

# Node (if installed)
npx serve .
```

ثم افتح: `http://localhost:8080`

## 🌐 النشر على Vercel | Deploy

1. ادفع المشروع إلى GitHub (الفرع `main`).
2. من لوحة تحكم Vercel: **Add New → Project → Import Git Repository**.
3. Vercel سيكتشف تلقائياً أنه موقع ستاتيك — اضغط **Deploy**.
4. خلال ثوانٍ سيكون الموقع على:
   `https://luxor-prayer.vercel.app`

> ملف `vercel.json` مضبوط لرؤوس الكاش والأمان فقط (بدون rewrites حتى لا تُحجب ملفات JS/CSS).
>
> ⚠️ عند تعديل `style.css` أو `app.js` أو `prayer-data.js` غيّر رقم الإصدار `?v=...` في `index.html` حتى يحصل الزوار على النسخة الجديدة فوراً بدل النسخة المخزّنة في الكاش.

## 🔧 الإعدادات المحفوظة محلياً | LocalStorage Settings

يحفظ الموقع تفضيلات المستخدم في `localStorage`:
- `lux_customName` — الاسم المعروض
- `lux_isSummerTime` + `lux_seasonSetAt` — التثبيت اليدوي للتوقيت الصيفي / الشتوي (يُلغى تلقائياً بعد أول تحويل رسمي للتوقيت، ويُحذف إذا طابق الوضع التلقائي)
- `lux_showIqama` — إظهار / إخفاء الإقامة

## 🕒 كيف يُحسب التوقيت؟ | Time Model

- بيانات `prayer-data.js` مخزّنة كلها بالتوقيت الصيفي (UTC+3).
- يحوّل التطبيق كل صلاة إلى لحظة زمنية مطلقة (UTC) ثم يعرضها بساعة الأقصر الحقيقية: UTC+3 في التوقيت الصيفي و UTC+2 في الشتوي.
- الساعة والعدّاد يعتمدان على توقيت الأقصر لا على توقيت جهاز الزائر، لذا تعمل بشكل صحيح من أي دولة.
- التوقيت الصيفي المصري: يبدأ الساعة 00:00 من آخر جمعة في إبريل وينتهي الساعة 24:00 من آخر خميس في أكتوبر.

## 🧩 البيانات المنظّمة | Structured Data

الصفحة تحتوي على JSON-LD واحد من نوع `@graph` يضم:

| النوع | الغرض |
|---|---|
| `WebSite` | تعريف الموقع باسمه البديل ولغته |
| `WebApplication` | إظهار التطبيق كتطبيق ويب مجاني مع قائمة المزايا |
| `Person` | بيانات المطوّر (عبد الرحمن ياسر الاسيوطي) + رقم التواصل |
| `Place` | محافظة الأقصر بإحداثياتها ومراكزها ومساجدها الشهيرة |
| `BreadcrumbList` | مسار التنقل (الرئيسية → مواقيت اليوم → الأسئلة الشائعة) |
| `FAQPage` | الأسئلة الشائعة — مطابقة نصّياً للأسئلة الظاهرة في الصفحة |

بالإضافة إلى `sitemap.xml` مع صور الموقع و`robots.txt`، ووسوم `hreflang` (ar / ar-EG / x-default)، وOpen Graph وTwitter Cards كاملة.

## 🖼️ كارت المشاركة 3:4 | Share Card

عند الضغط على زر «تحميل كارت»:

1. تُبنى بطاقة بعرض **1080px** وارتفاع **1440px** (نسبة 3:4 بالضبط).
2. تُصدَّر بواسطة `html2canvas` بمقياس **×2** → صورة **2160×2880** عالية الدقة.
3. تُرسم أيقونات الصلوات والتاج من SVG إلى PNG داخلياً (cached) لضمان ظهورها بحدّة على كل المتصفحات، مع الرجوع إلى SVG مباشرة لو تعذّر التحويل.
4. تاريخ الصورة: `mawaqit-aluxor-YYYY-MM-DD.png`.
